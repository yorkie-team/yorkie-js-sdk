    The top-level yorkie namespace with additional properties.

    In production, this will be called exactly once and the result assigned to the yorkie global.

    e.g) new yorkie.Client(...);

    It carries every runtime export this module exposes by name, so a default import and a namespace import agree. Before the exports map, the UMD was the only published entry and Node, esbuild and webpack handed out the whole module.exports as the default; keep that surface. A new runtime export belongs here too, and test/unit/yorkie_test.ts fails until it is added.
