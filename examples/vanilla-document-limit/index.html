    What are document limits?

    A Yorkie project can cap how many clients use one document at the same time. On Yorkie Cloud, set the caps in the Dashboard under your project's Settings, in the Resources section. 0 means no limit.

    Max Attachments Per Document
    How many clients can attach to the document. One more is rejected when it attaches, and this page says the document is full.
    Max Subscribers Per Document
    How many attached clients can watch the document for live changes. One more stays attached but shows Offline, and the SDK retries every second until someone leaves.

    Try it

    1. Set Max Attachments Per Document to 2 for the project whose API key this page uses. On Yorkie Cloud, use the Dashboard. On a local server, which the Dashboard can't see, log in with the CLI as the README shows and run yorkie project update default --max-attachments-per-document 2.
    2. Keep this tab open and open two more tabs of this page.
    3. The third tab can't attach and shows "This document is full".

    A changed setting can take up to 10 minutes to reach every server.
